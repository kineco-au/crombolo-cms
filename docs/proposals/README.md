# Crombolo — proposals

Ideas worth keeping that nobody has decided to build. A proposal records the
problem, the design as far as it was thought through, the alternatives, what it
would cost and what is still open, so the thinking is not lost and not redone.

A proposal is not planned work. Planned work is a story
([`../stories/README.md`](../stories/README.md)); the docs at the root of `docs/`
describe what exists. Nothing here is a commitment, and no story number is taken
until a proposal is accepted.

## How this directory works

- **One file per proposal,** named for what it proposes.
- **Each opens with its status and date:** `proposed`, `accepted` (with the stories
  cut from it), or `declined` (with why). A declined proposal stays, for the analysis.
- **Each has the same shape:** the problem, the proposal, alternatives considered,
  pros and cons, a recommendation, open decisions, and an outline of the work in
  enough detail to cut stories from.
- **When one is accepted** its work is written up as stories, the proposal names
  them, and the detail lives in the stories from then on.
